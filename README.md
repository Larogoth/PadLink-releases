# PadLink releases

Downloads of PadLink for Windows, used by PadLink's own updates. Get the newest: [PadLink-portable.zip](https://github.com/Larogoth/PadLink-releases/releases/latest/download/PadLink-portable.zip).

This repository also holds PadLink's website (GitHub Pages): <https://larogoth.github.io/PadLink-releases/>, with the
[privacy policy](https://larogoth.github.io/PadLink-releases/privacy.html) and the Google Drive picker (`picker/`).
